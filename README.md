# Employee Management System

## About the Project

The Employee Management System is a Java console-based application developed using Object-Oriented Programming concepts.

## Features

- Add Employee
- Search Employee
- Update Employee
- Display All Employees
- Exit the application

## Technologies Used

- Java
- Eclipse IDE
- OOP Concepts
- ArrayList

## OOP Concepts Used

- Class
- Object
- Constructor
- Encapsulation
- Methods

## Project Structure

EmployeeManagementSystem
│
└── src
    └── employee
        ├── Employee.java
        └── EmployeeManagement.java

## How to Run

1. Open the project in Eclipse.
2. Open `EmployeeManagement.java`.
3. Right-click the file.
4. Select `Run As`.
5. Select `Java Application`.
6. Choose an option from the menu.

## Sample Features

The application allows users to add employee details such as:

- Employee ID
- Name
- Department
- Salary

Users can also search and update employee information.
